# ターミナルキーバインド チートシート

Emacs モード（zsh デフォルト）のキーバインド一覧。macOS のテキスト入力全般でも多くが共通して使える。

---

## 移動

| キー | 動作 |
|------|------|
| `Ctrl+A` | 行頭へ移動 |
| `Ctrl+E` | 行末へ移動 |
| `Ctrl+F` | 1文字右へ移動 |
| `Ctrl+B` | 1文字左へ移動 |
| `Option+→` | 次の単語の末尾へ移動 |
| `Option+←` | 前の単語の先頭へ移動 |
| `Alt+F` | 次の単語へ移動（`Option+→` と同等） |
| `Alt+B` | 前の単語へ移動（`Option+←` と同等） |

---

## 削除

| キー | 動作 |
|------|------|
| `Ctrl+H` | カーソル前の1文字削除（Backspace と同等） |
| `Ctrl+D` | カーソル位置の1文字削除（Delete と同等） |
| `Ctrl+W` | カーソル前の単語を削除 |
| `Alt+D` | カーソル後の単語を削除 |
| `Option+Delete` | カーソル前の単語を削除（`Ctrl+W` と同等） |
| `Ctrl+U` | カーソルから行頭まで削除（キルリングに保存） |
| `Ctrl+K` | カーソルから行末まで削除（キルリングに保存） |

---

## ヤンク（貼り付け）

| キー | 動作 |
|------|------|
| `Ctrl+Y` | キルリングの内容を貼り付け（`Ctrl+U`/`K` で切った内容） |

> `Ctrl+U` → 修正 → `Ctrl+Y` でカット＆ペーストとして活用できる。

---

## 履歴

| キー | 動作 |
|------|------|
| `Ctrl+P` / `↑` | 前の履歴（入力済み文字列でフィルタ） |
| `Ctrl+N` / `↓` | 次の履歴（入力済み文字列でフィルタ） |
| `Ctrl+R` | 履歴をインクリメンタル検索 |

> `Ctrl+P`/`N` は入力済みの文字列でフィルタされる。例: `git` と入力して `Ctrl+P` → git コマンドの履歴のみ遡れる。

---

## 編集

| キー | 動作 |
|------|------|
| `Ctrl+_` | Undo（元に戻す） |
| `Option+Z` | Undo（元に戻す） |
| `Ctrl+T` | カーソル前後の2文字を入れ替え |
| `Alt+U` | カーソル位置から単語末尾を大文字に |
| `Alt+L` | カーソル位置から単語末尾を小文字に |

---

## その他

| キー | 動作 |
|------|------|
| `Ctrl+L` | 画面クリア |
| `Ctrl+C` | 実行中のコマンドを中断 |
| `Ctrl+Z` | プロセスをバックグラウンドに送る（`fg` で復帰） |
| `Ctrl+D` | EOF / シェル終了（入力が空のとき） |

---

## よく使う組み合わせ

```
# コマンドの一部だけ書き直す
Ctrl+A → 行頭へ → Option+→ で単語単位で移動 → Ctrl+W で単語削除

# 前のコマンドを再利用して引数だけ変える
Ctrl+P → 前の履歴を呼び出す → Ctrl+A → 行頭へ → 編集

# 長いコマンドのやり直し
Ctrl+U → 行頭まで切り取り → 別のコマンドを入力 → Ctrl+Y で元の内容を貼り付け
```
